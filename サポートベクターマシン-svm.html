Chapter 11 サポートベクターマシン (SVM)

本章の内容は, 授業の R 演習スクリプト R_SVM_dist.R に対応する.

サポートベクターマシン (SVM) は, 説明変数の空間を分割する決定境界を データから直接推定するアプローチである識別モデル (discriminative model) と呼ばれる クラス分類手法の一つである.

SVMは, 原理的には, 2クラス分類問題に対して適用される. 多クラス分類問題に対しては, 複数の2クラス問題に分割し, 各々にSVMを適合して得られた個々の分類結果を統合する形で解決を図る.

SVMは, 多次元の説明変数の空間上に布置された2クラスの点の集合に対して, “マージン” (境界面から一番近い点までの距離) が最大となるという意味において, 2グループができるだけうまく分離されるような平面 (境界面) を引くことを試みる. その際, 完全な分離ではなく, 分類の失敗 (誤判別) やマージン違反を許容するような 平面を引く. 許容の程度はハイパーパラメータ (コスト \(C\)) を通じて分析者がSVMに与える.

また, SVMは, カーネル関数を上手に選択することで, 説明変数空間における 境界面がドーナツ型を含む非線形な形状をしているようなケースにも柔軟に対応することができる.

どのように非線形なケースに対応するかについてその原理を大雑把に述べると,

  • 数学的には, 再生核ヒルベルト空間 (RKHS) の理論に基づいている
  • データ点が配置されている元の空間から, 非線形な写像によって高次元 (または無限次元) の空間へ写される
  • その高次元の空間で, 線形な平面 (超平面) を引いて分割する
  • すると, 元の空間では非線形な分割がなされている (非線形SVM)
  • 各データ点を高次元の空間に写す非線形な変換を, 実際に計算する必要はない
  • よって, 非線形な変換のことは忘れて (無視して), カーネル関数を選べば良い (“カーネルトリック”)

ちなみに, 本章では扱わないが, SVMは, 回帰問題にも応用することができる (サポートベクター回帰). そこでは, やはりカーネル関数をうまく選択することで説明変数の元の空間内では非線形な形状の回帰曲面を得ることができる. また, 分類問題におけるマージン違反の許容に対応するものとして, 最小二乗法の代わりに, 回帰残差の絶対値が閾値以上のもののみを損失として数える損失関数を最小化する問題を解いている.

なお, SVMにおいても, 学習データに対するモデルの過剰・過小学習を避けるには, 交差検証などによりハイパーパラメータのチューニングを適切に行う必要がある.

本章では, SVMの中でも, 恐らくもっともポピュラーな (Gaussian) RBFカーネルを中心に説明する. パッケージkernlabの関数ksvm(), e1071のsvm()を用いる.

11.1 RBF カーネル SVM の特徴

データ: 社債発行体の格付 (仮想データ, 第8章と同じ)

rating.csv: 600社 (仮想データ)
- rating: 格付 (A, BBB, HY)
- mcap: 時価総額 (億円), debt_ebitda: 有利子負債/EBITDA (倍)
- int_coverage: インタレスト・カバレッジ (倍), roa (%), equity_ratio (%), equity_vol (%)
rating <- read.csv("class/rating.csv", stringsAsFactors = TRUE)
rating$rating <- factor(rating$rating, levels = c("A", "BBB", "HY"))
rating$log_mcap <- log(rating$mcap)
rating$log_icr <- log(rating$int_coverage)
table(rating$rating)
#> 
#>   A BBB  HY 
#> 210 240 150

SVM の特徴を理解するため, BBB と HY の2クラス, 説明変数2つ (log_mcap, debt_ebitda) に絞って分析する. データ点が多いと, ハイパーパラメータを変えたときの境界の形の変化が見えにくいので, 100社を無作為に抽出して使う.

rt1 <- subset(rating, rating != "A", select = c(log_mcap, debt_ebitda, rating))
rt1$rating <- droplevels(rt1$rating)
set.seed(1)
rt1 <- rt1[sample(nrow(rt1), 100), ]
table(rt1$rating)
#> 
#> BBB  HY 
#>  65  35

SVMの実行

パッケージkernlab, 関数ksvm()を使用する.

library(kernlab)
rt_ksvm <- ksvm(rating ~ ., data = rt1)  # デフォルト (kpar = 'automatic')
rt_ksvm  # サポートベクターの数, 学習誤差
#> Support Vector Machine object of class "ksvm" 
#> 
#> SV type: C-svc  (classification) 
#>  parameter : cost C = 1 
#> 
#> Gaussian Radial Basis kernel function. 
#>  Hyperparameter : sigma =  0.831228198679164 
#> 
#> Number of Support Vectors : 64 
#> 
#> Objective Function Value : -49.0948 
#> Training error : 0.19
table(予測 = predict(rt_ksvm, rt1[, 1:2]), 実績 = rt1$rating)
#>      実績
#> 予測 BBB HY
#>   BBB  59 13
#>   HY    6 22
plot(rt_ksvm, data = rt1[, 1:2])

予測変数が2つの2値分類なので, 境界を可視化できる. 図の色は判別関数の値で, 白い帯 (値が0付近) が分離境界にあたる. 記号の違い (○ と △) がクラスを, 塗りつぶされた点がサポートベクターを表す. なお, kpar = "automatic" では, sigma の値がデータから乱数を使って自動的に決められる.

ハイパーパラメータ (sigma, C) の値を変えて実行してみる. kernlab の sigma は, スライドの RBF カーネルの \(\gamma\) に相当する.

rt_ksvm <- ksvm(rating ~ ., data = rt1, kpar = list(sigma = 10))  # → より複雑な境界
rt_ksvm
#> Support Vector Machine object of class "ksvm" 
#>

#>  parameter : cost C = 1 
#> 
#> Gaussian Radial Basis kernel function. 
#>  Hyperparameter : sigma =  10 
#> 
#> Number of Support Vectors : 81 
#> 
#> Objective Function Value : -44.023 
#> Training error : 0.08
plot(rt_ksvm, data = rt1[, 1:2])

rt_ksvm <- ksvm(rating ~ ., data = rt1, kpar = list(sigma = 0.1))  # → より大雑把な境界
rt_ksvm
#> Support Vector Machine object of class "ksvm" 
#> 
#> SV type: C-svc  (classification) 
#>  parameter : cost C = 1 
#> 
#> Gaussian Radial Basis kernel function. 
#>  Hyperparameter : sigma =  0.1 
#> 
#> Number of Support Vectors : 62 
#> 
#> Objective Function Value : -55.7124 
#> Training error : 0.25
plot(rt_ksvm, data = rt1[, 1:2])

sigma が大きいと, 各データ点の影響が及ぶ範囲が狭くなり, 学習データに細かく合わせた複雑な境界になる (過学習しやすい). sigma が小さいと, 滑らかで大雑把な境界になる.

rt_ksvm <- ksvm(rating ~ ., data = rt1, kpar = list(sigma = 0.1), C = 10)  # → より少ない SV
rt_ksvm
#> Support Vector Machine object of class "ksvm" 
#> 
#> SV type: C-svc  (classification) 
#>  parameter : cost C = 10 
#> 
#> Gaussian Radial Basis kernel function. 
#>  Hyperparameter : sigma =  0.1 
#> 
#> Number of Support Vectors : 54 
#> 
#> Objective Function Value : -496.0492 
#> Training error : 0.24
rt_ksvm <- ksvm(rating ~ ., data = rt1, kpar = list(sigma = 0.1), C = 0.01)  # → より多くの SV
rt_ksvm
#> Support Vector Machine object of class "ksvm" 
#> 
#> SV type: C-svc  (classification) 
#>  parameter : cost C = 0.01 
#> 
#> Gaussian Radial Basis kernel function. 
#>  Hyperparameter : sigma =  0.1 
#> 
#> Number of Support Vectors : 71 
#> 
#> Objective Function Value : -0.6978 
#> Training error : 0.35
plot(rt_ksvm, data = rt1[, 1:2])

C は誤判別・マージン違反に対するコストである. C が小さいと, マージン違反を大目に見る代わりにマージンを広く取るので, サポートベクターが多くなる. C = 0.01 では, ほとんどの点がサポートベクターとなり, 全ての点を多数派のクラス (BBB) に判別している. C が大きいと, マージン違反を厳しく罰するので, マージンは狭く, サポートベクターは少なくなる.

自主課題 sigma と C の組合せを変えて, 境界の形やサポートベクターの数, 学習誤差がどう変わるか試してみよう.

11.2 2値分類

データ: クレジットカードの延滞 (実データ: UCI Machine Learning Repository)

台湾のクレジットカード会員 30,000人のデータ (2005年4月〜9月) である (Yeh and Lien, 2009). UCI Machine Learning Repository の “Default of Credit Card Clients” から, zip ファイル (中身は Excel ファイル) を直接ダウンロードして読み込む.

- default: 翌月の延滞 (yes / no) (目的変数)
- limit_bal: 利用枠 (NT ドル), sex: 性別, education: 学歴, marriage: 婚姻状況, age: 年齢
- pay_1〜pay_6: 1〜6か月前の支払状況 (-2, -1, 0: 遅延なし, 1〜9: 遅延の月数)
- bill_amt1〜bill_amt6: 1〜6か月前の請求額 (NT ドル)
- pay_amt1〜pay_amt6: 1〜6か月前の支払額 (NT ドル)

元データの変数名を小文字にそろえ (最新月の PAY_0 は pay_1 に改名), 質的変数 (性別, 学歴, 婚姻状況) を factor 型に変換する. 学歴と婚姻状況のうち, 説明書きにないコード (学歴の 0, 5, 6 など) は「その他 (other)」にまとめた.

library(tidyverse)
library(readxl)  # Excel ファイル (.xls) の読み込み
url <- "https://archive.ics.uci.edu/static/public/350/default+of+credit+card+clients.zip"
tmp <- tempfile(fileext = ".zip")
download.file(url, tmp, mode = "wb", quiet = TRUE)
xls <- unzip(tmp, exdir = tempdir())
raw <- read_excel(xls, skip = 1)  # 1行目は列番号なので読み飛ばす
card_all <- raw %>%
  dplyr::select(-ID) %>%
  rename(default = `default payment next month`, PAY_1 = PAY_0) %>%
  rename_with(tolower) %>%
  mutate(default = factor(default, levels = 0:1, labels = c("no", "yes")), sex = factor(sex,

ksvm() の主な引数:
- kernel: "rbfdot" (Gaussian RBF, デフォルト), "vanilladot" (線形), "polydot" (多項式)

ROC 曲線と AUC

延滞確率をスコアとして, しきい値によらない比較を行う. 比較のため, ロジット回帰も推定する.

library(ROCR)
auc <- function(score, y) performance(prediction(score, y), "auc")@y.values[[1]]
p_lin <- predict(card_lin, card_test, type = "probabilities")[, "yes"]
p_rbf <- predict(card_rbf, card_test, type = "probabilities")[, "yes"]
p_glm <- predict(glm(default ~ ., family = binomial, data = card_train), card_test,
  type = "response")
round(c(SVM_linear = auc(p_lin, card_test$default), SVM_rbf = auc(p_rbf, card_test$default),
  logit = auc(p_glm, card_test$default)), 3)
#> SVM_linear    SVM_rbf      logit 
#>      0.675      0.704      0.714
plot(performance(prediction(p_rbf, card_test$default), "tpr", "fpr"), col = "blue")
plot(performance(prediction(p_glm, card_test$default), "tpr", "fpr"), col = "red",
  add = TRUE)
abline(0, 1, lty = 3)
legend("bottomright", legend = c("SVM (RBF)", "ロジット"), col = c("blue", "red"),
  lty = 1)

線形カーネルより RBF カーネルの方が AUC は高いが, ロジット回帰の AUC も同程度 (このサンプルではやや高い) である. 表形式 (構造化) データでは, SVM が常に最良とは限らない. 複数の手法を比較することが大切である.

11.3 多クラス分類

全ての財務指標を使って, A / BBB / HY の3クラスを判別する. ksvm() は, クラス数が3以上の場合, One-versus-One (OvO) 法 (全てのクラスの組合せについて2値分類の SVM を学習し, 多数決で判別) で分類する.

set.seed(1)
train_idx <- sample(nrow(rating), 400)
fo <- rating ~ log_mcap + debt_ebitda + log_icr + roa + equity_ratio + equity_vol
rt_train <- rating[train_idx, ]
rt_test <- rating[-train_idx, ]

for (s in c(0.01, 0.1, 1)) for (C in c(0.1, 1, 10)) {
  m <- ksvm(fo, data = rt_train, kpar = list(sigma = s), C = C)
  acc <- mean(predict(m, rt_test) == rt_test$rating)
  cat(sprintf("sigma = %5.2f, C = %5.1f: SV数 = %3d, テスト正解率 = %.3f\n",
    s, C, m@nSV, acc))
}

tune() の使い方のヒント:
- 引数 tunecontrol の値を関数 tune.control() で設定できる
- 例: tunecontrol = tune.control(sampling = "boot")
  sampling: "cross" (交差検証, デフォルト), "boot" (ブートストラップ), "fix" (1回だけ分割)
