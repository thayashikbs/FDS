Chapter 6 正則化回帰 (lasso, ridge回帰, elastic net)

本章の内容は, 授業の R 演習スクリプト R_lasso_dist.R に対応する.

本章では, Rパッケージglmnetを使用する. 同パッケージは, Lasso (Least Absolute Shrinkage and Selection Operator) やその拡張 (Elastic Net 等) の理論研究や応用を推進した Jerome Friedman, Trevor Hastie, Robert Tibshirani らによって開発され, 維持されている.

glmnetに関する有用なマニュアル, 解説ページ:

  • https://glmnet.stanford.edu/articles/glmnet.html
  • https://cran.r-project.org/web/packages/glmnet/vignettes/glmnet.pdf

※ 本章における分析の流れは, 主として ISLR2, Ch.6 (Lab: Linear Models and Regularization Methods) を参考にした.

6.1 検証用セット法による回帰モデルの予測精度評価

データ1: 社債の信用スプレッドと企業特性 (仮想)

- credit_spread.csv, 500社 x 31変数
  - spread: 社債の信用スプレッド (bp) (目的変数)
  - 収益性: roa, roe, op_margin, ebitda_margin (%)
  - 負債・返済能力: debt_assets (%), debt_equity (倍), net_debt_ebitda (倍), int_coverage (倍)
  - 流動性: current_ratio, quick_ratio (倍), cash_assets (%)
  - 規模: log_assets, log_sales, log_mcap (対数), employees_k (千人)
  - 株式市場: equity_vol (%), beta, max_drawdown (%)
  - 成長・投資: sales_growth, capex_assets, asset_growth (%)
  - その他: rd_sales, payout, foreign_own, firm_age, board_indep, inventory_turn,
            receivable_days, tokyo, listed_years

説明変数が30個と多く, しかも同じ種類の指標どうし (例えば, 収益性の4指標) は強く相関している. このような状況では, 全変数を使った最小二乗法 (OLS) の推定は不安定 (係数のばらつきが大きい) になりやすく, 予測精度も下がりやすい. 正則化回帰は, 係数をゼロの方向に縮めることで推定のばらつきを抑え, 予測精度の改善を図る. ただし, 相関の強い変数に対する振る舞いは手法によって異なる. ridge回帰は相関の強い変数の係数を互いに近い値に縮めて推定を安定させるのに対し, lasso は相関の強い変数のグループから一部の変数だけを選び, どれが選ばれるかはデータの少しの違いで変わりやすい. elastic net は, 両者の中間的な性質を持つ (以下で確かめる).

library(glmnet)  # Lasso and Elastic-Net Regularized Generalized Linear Models
cs <- read.csv("class/credit_spread.csv")
dim(cs)
#> [1] 500  31
round(cor(cs[, c("roa", "roe", "op_margin", "ebitda_margin", "debt_assets", "debt_equity")]),
  2)

6.2 lasso

関数glmnet()の基本操作

glmnet(): 罰則付き最尤法: GLM の推定 + elastic net による正則化
- usage: glmnet(x, y, family = c("gaussian", "binomial", "poisson", "multinomial", "cox", "mgaussian"), ...)
- 最重要パラメータ
  - alpha: elastic net 混合パラメータ (デフォルト = 1)
  - lambda: 正則化パラメータ (デフォルトは自動的に100個設定)

glmnet()は, lm()のようなモデル式ではなく, 説明変数の行列 x と目的変数のベクトル y を引数に取る. そこで, あらかじめ x と y を別々のオブジェクトとして用意しておく.

x <- as.matrix(cs[, -1])
y <- cs$spread

lasso を実行するには, glmnet()において, 引数alpha = 1と設定する. \(\alpha\)は, lasso, ridge回帰 (後述) を包括するクラスである elastic net のパラメータであり, 両者の正則化項の結合ウェイトを示す (\(\alpha=1\) が lasso, \(\alpha=0\) が ridge回帰に対応). 特定のlambdaの値二つに対して実行し, 結果を比較してみる.

# lambda: 罰則 (L1 ペナルティ) の強さ
lasso_mod <- glmnet(x[train, ], y[train], alpha = 1, lambda = 10)  # lambda 大 → 係数 = 0 が多い

最初の例 (lambda = 10), すなわち, 正則化項の係数が相対的に大きい (罰則が大きい) とき, 多くの回帰係数の値がゼロ (.) になる (変数が選択されない). 他方, 二番目の例 (lambda = 1), すなわち, 罰則が小さいときは, 非ゼロの係数が増える. lasso は, 係数の推定と変数の選択を同時に行う.

lambdaのグリッド指定によるglmnet()の一括実行

正則化パラメータ\(\lambda\)は, 数値ベクトルとして関数glmnet()に与えることもできる. すると, 各lambdaの値に対してglmnet()が実行され, それらが一括して戻ってくる. 以下では, \(10^2\)から\(10^{-2}\)まで100個の点からなるグリッドを関数glmnet()に与える.

grid <- 10^seq(2, -2, length = 100)  # lambda = 10^2 〜 10^(-2)
lasso_mod <- glmnet(x[train, ], y[train], alpha = 1, lambda = grid)
dim(coef(lasso_mod))  # 31行 (切片 + 30変数) x 100列 (lambda の値)
#> [1]  31 100

交差検証によるパラメータ・チューニング

関数cv.glmnet()は, 交差検証 (cross-validation) を使って, 正則化パラメータ\(\lambda\)の”最適な”値を探す.

- cv.glmnet(): k-分割交差検証を行い, CV誤差の曲線と最適な lambda を返す
set.seed(2)
cv_out <- cv.glmnet(x[train, ], y[train], alpha = 1, lambda = grid, nfolds = 10)
plot(cv_out)  # 上の数字: 非ゼロの係数の数

“最適な”\(\lambda\)の決め方の一つは, CV誤差 (予測MSEの推定値) が最小となる \(\lambda\)の値であり, これはcv.glmnet()の出力の 要素$lambda.minに格納されている. この値をpredict()の引数sに与えることで, 対応する lasso のモデルによる予測ができる.

(bestlam <- cv_out$lambda.min)
#> [1] 1.384886
lasso_pred <- predict(lasso_mod, s = bestlam, newx = x[-train, ])
mean((lasso_pred - y[-train])^2)  # テストMSE
#> [1] 1522.164

代替的な\(\lambda\)の決め方としてよく用いられる方法に, 1標準誤差ルール (1 standard error rule) がある. これは, CV誤差の最小値 (\(CV_{min}\)) と, その時の標準誤差 \(se_{min}\) に対して, \(CV_{\lambda} \le CV_{min} + se_{min}\) となる\(\lambda\)の中で 最大の\(\lambda\)を選ぶものである. CV誤差最小の\(\lambda\)よりも大きな\(\lambda\)を取ることで, 選ばれる変数の数が減り, よりシンプルなモデルが選ばれる.

(lmbd_1se <- cv_out$lambda.1se)
#> [1] 4.641589
lasso_pred2 <- predict(lasso_mod, s = lmbd_1se, newx = x[-train, ])
mean((lasso_pred2 - y[-train])^2)
#> [1] 1500.546

6.4 elastic net

6.5 一般化線形モデル (GLM) + 正則化

関数glmnet()はその名が示すように, 線形回帰にとどまらず, 一般化線形モデル (GLM) に対しても, elastic net (lasso, ridge回帰) を実行することができる. 引数familyに, デフォルト (gaussian) 以外の 適切な確率分布を指定する.

family = c("gaussian", "binomial", "poisson", "multinomial", "cox", "mgaussian")

glmnet()は, lm()やglm()等とは使い方が異なる点に注意が必要である.

glmnet() 実行上の注意点
 - 欠損値 (NA) の事前処理が必要: 除去 or 補完
 - モデル式ではなく, matrix クラスの x, ベクトルの y を引数に取る
 - 説明変数は数値のみ (x は行列) → 質的変数 (factor) はダミー変数化が必要
   → model.matrix() で説明変数行列 (design matrix) を作る (質的変数は自動でダミー変数化)

6.6 補足: GLM に対する変数選択の代替的方法

最後に, 正則化回帰ではないが, GLM に対する変数選択の代替的方法として, glm() + step() を紹介する. ここでは, 信用スプレッド・データをそのまま (family = gaussian, すなわち線形回帰として) 使う.

- step(): AIC 基準によるステップワイズ法でモデルを選択
- glm() では NA は自動的に除かれるが, step() では行数が変わるとエラー
  → 欠損値 (NA) の事前処理が必要: 除去 or 補完
res_glm <- glm(spread ~ ., data = cs[train, ])
res_step <- step(res_glm, trace = 0)
