Chapter 12 主成分分析 (PCA)

本章の内容は, 授業の R 演習スクリプト R_pca_dist.R に対応する.

主成分分析 (principal component analysis, PCA) は, 互いに相関のある多数の変数を, 情報の損失をできるだけ小さくしながら, 互いに無相関な少数の合成変数 (主成分) に集約する手法である. 第1主成分は, 変数の線形結合のうち分散が最大となるもの, 第2主成分は, 第1主成分と無相関なもののうち分散が最大となるもの, … と順に定められる. 主成分の係数を主成分負荷量, 各個体の主成分の値を主成分得点と呼ぶ.

R では, 標準パッケージの関数princomp()とprcomp()で実行できる.

  • princomp(): 分散共分散行列 (引数 cor = TRUE なら相関行列) を固有値分解して計算する. 分散は n で割る.
  • prcomp(): 中心化した (引数 scale. = TRUE なら標準化もした) データ行列を特異値分解 (SVD) して計算する. 分散は n − 1 で割る (不偏分散).

両者の主成分負荷量は (符号を除いて) 一致し, 寄与率も同じである. 違うのは主成分の標準偏差 (n と n − 1 の違いによる) だけである. R のヘルプでは, 数値計算の精度の点で prcomp() (特異値分解) が推奨されている. また, princomp() は変数の数が個体数より多い場合には使えない.

library(tidyverse)

12.1 分散共分散行列か, 相関行列か: USArrests

USArrests: n = 50, p = 4

分散共分散行列に対する PCA では, 第1主成分の負荷量はほぼ Assault だけで決まり, 第1主成分だけで全変動の97%を説明する. これは, 4つの変数の関係を捉えた結果ではなく, 単に Assault の分散が大きいことを反映しているに過ぎない. 一方, 相関行列に対する PCA (各変数を標準化) では, 第1主成分は3種類の犯罪の逮捕者数にほぼ同じ大きさの負荷量を持ち (「凶悪犯罪の多さ」. ここでは負荷量の符号が負なので, 得点が小さいほど凶悪犯罪が多い), 第2主成分は主に UrbanPop (「都市化の程度」) を表している.

単位や散らばりの大きさが異なる変数を扱う場合は, 各変数を標準化する (相関行列に対する PCA を行う) のが基本である. 逆に, 全ての変数の単位がそろっていて, 散らばりの大きさの違い自体に意味がある場合 (例えば, 同じ満点の評価項目や, 同じ単位の金利変化) は, 分散共分散行列に対する PCA を使って良い.

# PCA にかける変数の絞り込み
prcomp(~Murder + Assault + Rape, data = USArrests, scale. = TRUE)

princomp() と prcomp() では, 主成分負荷量・主成分得点の符号が逆になっている主成分がある. 主成分の符号は一意に定まらない (負荷量ベクトルの向きを反転させても, 分散や他の主成分との無相関性は変わらない) ので, 解釈しやすい向きに読み替えて良い. また, prcomp() は不偏分散を使うので, 主成分の標準偏差の値も少し異なる (寄与率は同じ).

(参考) 固有値分解と特異値分解

princomp() は分散共分散行列の固有値分解, prcomp() はデータ行列の特異値分解で計算するが, 得られる主成分は同じである. 中心化したデータ行列 \(X\) (\(n \times p\)) を \(X = UDV'\) と特異値分解すると, \(V\) の列が主成分負荷量 (分散共分散行列の固有ベクトル), \(XV = UD\) が主成分得点, \(D^2/(n-1)\) が固有値 (主成分の分散) になる. 分散共分散行列 \(X'X/(n-1)\) を明示的に作らずに計算できるので, 数値計算の誤差が小さい.

X <- scale(eval9, scale = FALSE)  # 中心化したデータ行列
e <- eigen(cov(X))  # 分散共分散行列の固有値分解
sv <- svd(X)  # データ行列の特異値分解 X = UDV'
round(cbind(固有ベクトル = e$vectors[, 1], V = sv$v[, 1]), 3)  # 第1主成分負荷量 (符号を除いて一致)

#> [3,]        0.486  0.486
#> [4,]        0.618  0.618
#> [5,]        0.531  0.531
round(rbind(固有値 = e$values, `D^2/(n-1)` = sv$d^2/(nrow(X) - 1)), 3)

典型的な解釈 (Litterman and Scheinkman, 1991):

  • 第1主成分: 水準 (level). 全期間の利回りがほぼ同じ方向に動く
  • 第2主成分: 傾き (slope). 短期と長期の利回りが逆方向に動く
  • 第3主成分: 曲率 (curvature). 中期と, 短期・長期の利回りが逆方向に動く

符号は一意に定まらないので, 解釈しやすい向きに読み替えて良い. 債券ポートフォリオの金利リスク管理では, この3つの主成分に対する感応度でリスクを把握することがある.
